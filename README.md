# FIRST BLAST

Three.jsで作られた、オフライン1対1アリーナFPSです。左右対称マップでCPUと一命制のラウンドを戦い、先に5ラウンド取ると勝利します。

特定作品のロゴ・モデル・音源・画像は使用せず、高速なデュエル、4スロットのロードアウト、スライドを中心にした独自のブラウザゲームとして構成しています。

## 主な機能

- 5ラウンド先取の1対1 CPU DUEL
- 5人のライバルを連続で倒す、オフラインのRIVAL CIRCUIT
- Scatter / Pulse / Rail / Cannonを使い分けるCPUと、戦況で武器を変える最終ボス
- Primary / Secondary / Melee / Utilityの4スロット
- 各スロット2種類、合計8種類の装備
- ADS、スプリント、しゃがみ、スライド、クイック近接、クイックUtility
- 遮蔽物や壁の上に登れる縦の移動。低い縁は歩いて越え、天面を歩き、端から落ちる
- 高所へ登ったプレイヤーを、CPUも段差を跳んで追いかける
- ヘッドショットと距離減衰
- 遮蔽物で止まるCPUの実弾
- 方向別被弾表示、撃破コールアウト、低HP警告などの戦闘フィードバック
- ラウンド間に最大3個まで選ぶ5種類の試合内ギア
- RUSHER / TACTICIAN / MARKSMANのCPU戦闘スタイル
- CROSSLINE / POCKET / LONGSHOT / SUMMITの4アリーナ
- 雪山と遠景の山並みを持つ大型ステージSUMMIT（風車状の中央基地、両サイドの狙撃レーン、頭上ガントリー、壁の上へ登る足場）
- 射撃場と移動する練習ターゲット
- 永続保存されるロードアウト、設定、契約、KEY
- 契約とDUEL勝利で得るKEYを使い、武器カラー、着弾エフェクト、称号を解放するSTYLE LOCKER
- Circuitの最高到達点・ベストタイムと、完全制覇で解放される限定STYLE報酬
- 命中率、撃破、総ダメージ、最大一撃、被ダメージ、クラッチを表示するリザルト
- PCとタッチ操作に対応
- ギアに頼らず最初から使える、高く素早い標準ジャンプ（上昇・頂点・落下で重力を切り替え、滞空を短く保つ）
- スライド中／直後のジャンプは前方向の勢いを引き継ぎ、通常ジャンプより少し遠くへ跳ぶ
- スマホ向けのJump Buffer、Coyote Time、自動連続ジャンプ、強い空中制御
- タッチ操作中だけ働く、壁判定・Slowdown・短時間ターゲット保持付きエイムアシスト

## 描画

見た目まわりは `graphics.js` に集約し、設定画面の「画質」で段階を切り替えます。

- Neutralトーンマッピングで、日なたの白い床や雪が真っ白に潰れず陰影を保つ
- アリーナ全体を覆う影。太陽光の影用カメラを42mのアリーナに合わせ、遮蔽物・ガントリー・ライバルが床に影を落とす
- 表面はラフネス／メタルネス付きのStandardマテリアル。コンクリート、鉄骨、氷がそれぞれ違う光り方をする
- 空のグラデーションから作った環境マップ。金属と縁に柔らかい映り込みが乗る
- 遠くの床でスタッドや雪の模様が潰れないよう、テクスチャに異方性フィルタを適用

| 画質 | 影 | マテリアル | 解像度 |
| --- | --- | --- | --- |
| 低 | なし（弱いアンビエントで補正） | Lambert | 最大1.25倍 |
| 中 | 1024・PCF | Standard | 最大1.25倍 |
| 高 | 2048・ソフトPCF | Standard | 最大2倍 |

既定は端末を問わず「中」です。スマートフォンでも影と質感はそのまま出ます。負荷を下げたい場合だけ設定画面で「低」を選んでください（一度自分で選ぶと、その選択が優先されます）。

画質を変えると、解像度・影・トーンマッピングはその場で切り替わります。マテリアルの種類はモデルを組み立てた時点で決まるため、低と中／高の行き来はアリーナの再生成か再読み込みで反映されます。

## 起動

ES ModulesとThree.js CDNを使うため、ファイルを直接開かずローカルHTTPサーバーを使います。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。初回読み込み時はThree.js取得のためインターネット接続が必要です。

## PC操作

- `WASD`: 移動
- マウス: 視点
- 左クリック: 射撃・使用
- 右クリック: ADS
- `Shift`: スプリント
- `C` または `Ctrl`: しゃがみ／移動中はスライド
- `Space`: ジャンプ
- `R`: リロード
- `1`〜`4`: 武器スロット切替
- `Q`: クイック近接
- `E`: クイックUtility
- `Esc`: メニューへ戻る

## スマートフォン操作

- 左スティック: 移動・空中制御
- 右側ドラッグ: 視点操作
- `FIRE`: 射撃
- `JUMP`: ジャンプ。押し続けると着地時に自動で再ジャンプ
- `R`: リロード
- 武器スロット: 武器切り替え

エイムアシスト、自動連続ジャンプ、視点感度、ジャンプ／射撃ボタンのサイズと位置は設定画面で変更できます。開発時はURLへ `?forceTouch=1&touchDebug=1` を付けると、タッチUIとエイム・ジャンプ状態のデバッグ表示を確認できます。

## ゲームモード

### DUEL

プレイヤーかCPUのHPが0になるとラウンド終了です。次のラウンドでは位置、HP、弾薬がリセットされ、先に5本取った側が試合に勝利します。

### RIVAL CIRCUIT

JET、VEX、SCOPE、TITAN、ZEROの5人と順番に戦う一人用チャレンジです。各ステージは対戦前に相手の武器、戦闘スタイル、アリーナ、弱点を確認できます。最初の4戦は3本先取、最終戦ZEROは5本先取です。勝利ごとにKEYを獲得し、完全制覇すると限定武器カラーと称号が解放されます。最高到達点、クリア回数、ベストタイムはブラウザに保存されます。

### 射撃場

反撃しないターゲットで、射撃、ヘッドショット、近接、Utilityを自由に練習できます。ターゲットを倒すと別位置に再出現します。

## ロードアウト

- Primary: Pulse Rifle / Scatter Blaster
- Secondary: Spark Pistol / Bubble Sidearm
- Melee: Energy Baton / Boost Blade
- Utility: Bounce Grenade / Heal Capsule

選択内容、契約進捗、獲得KEY、設定はブラウザの `localStorage` に保存されます。
