# FIRST BLAST

Three.jsで作られた、初心者や子どもも遊びやすい3DアリーナFPSのプロトタイプです。PCとスマートフォンの両方に対応し、ビルド不要でGitHub Pagesへ公開できます。

## 起動方法

ES Modulesを利用するため、ファイルを直接開かずローカルHTTPサーバーを使用してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、難易度またはリラックスモードを選んで **BLAST OFF** を押します。

## 操作

### PC

- `WASD`: 移動
- マウス: 視点操作
- 左クリック: 射撃
- `Space`: ジャンプ
- `Shift`: 短距離ダッシュ
- `R`: リロード
- `1` / `2` / `3`: 武器切り替え

### スマートフォン・タブレット

- 左側の仮想スティックで移動し、右側の空き領域をドラッグして視点を操作します。
- 射撃・JUMP・DASHを複数の指で同時に操作できます。
- 画面下部の武器ボタンで武器を切り替えられます。
- セーフエリア、縦・横画面、左利き配置、変更可能なボタンサイズに対応しています。

## 武器

- **Pulse Blaster**: 20発。扱いやすい青白い中距離連射武器です。
- **Spark Shot**: 6発。黄色い電撃を複数発射する近距離向け拡散武器です。距離によって威力が下がります。
- **Bubble Launcher**: 4発。ゆっくり飛び、着弾地点の周囲へ爆発ダメージを与えるエネルギー球です。

各武器には低ポリゴンのFPSモデル、発射・リロード・切り替えアニメーション、固有のWeb Audio電子音があります。

## 難易度とモード

- **かんたん**: プレイヤーHP 200、CPU HP 80。CPUの移動・反応・命中率を抑え、エイムアシストを強くしています。
- **ふつう**: プレイヤーHP 150、CPU HP 100。標準的なCPU行動とエイムアシストです。
- **チャレンジ**: プレイヤーHP 100、CPU HP 120。CPUが素早く、ジャンプやダッシュを使いやすくなります。
- **リラックスモード**: 自動回復、弾薬無制限、リロード不要、低いCPU攻撃力、敗北なしで自由に遊べます。

選択した難易度はブラウザの `localStorage` に保存されます。

## CPU・サポート機能

CPUはプレイヤーとの距離を調整しながら左右移動し、壁や障害物との間に遮蔽物がない場合だけ射撃します。低HP時は回復アイテムを探し、難易度に応じてジャンプや短距離ダッシュも使用します。連射後には休止時間があります。

通常モードで3回連続して倒されると、青い**サポートドローン**が出現します。ドローンはプレイヤーの近くを飛び、少量の回復と低ダメージ射撃で立て直しを支援します。プレイヤーが2回撃破すると退場します。リラックスモードでは最初から登場します。

## アイテムとステージ

アリーナには、時間経過で再出現する回復、弾薬、シールド、スピードアップアイテムがあります。高台、坂、橋、短いトンネル、コンテナ、円柱、低い壁、3基のジャンプ台を追加し、4エリアを青・黄色・緑・ピンクで区別しています。

## 設定画面

タイトル画面の設定から、効果音・BGM音量、視点感度、エイムアシスト、カメラ振動、照準サイズ・色、タッチボタンサイズ、左利き配置、低・中・高の画質を変更できます。設定値が壊れている場合は安全な初期値へ戻ります。

## GitHub Pagesへの公開

1. このフォルダーをGitHubリポジトリのデフォルトブランチへpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. Sourceで **Deploy from a branch** を選びます。
4. デフォルトブランチと **/(root)** を選択して **Save** を押します。
5. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を開きます。

## 現在の制限事項

- Three.jsをCDNから読み込むため、初回起動時にはインターネット接続が必要です。
- CPUの移動は軽量なステアリング方式で、本格的なナビゲーションメッシュは使用していません。
- BGM音量設定は将来のBGM追加用です。現在は著作権フリーのWeb Audio効果音のみです。
- GPU性能が非常に低い端末では、設定から画質を「低」にしてください。
